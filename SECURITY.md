# Security policy

## Supported versions

The latest release on [rubygems.org](https://rubygems.org/gems/card_dealer) receives security fixes. Older releases do not.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use one of these private channels:

- [GitHub private vulnerability reporting](https://github.com/svyatov/card_dealer/security/advisories/new)
- Email to leonid@svyatov.com

You will get a reply within 14 days. A fix ships as a new gem release, and the advisory is published after it.
